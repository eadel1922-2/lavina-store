لافينا LAVINA - متجر ملابس حريمي - النسخة V.002
=================================================

ما الجديد في V.002 مقارنة بـ V.001
-----------------------------------
- إضافة حقلَي التقييم لكل منتج: الدرجة (من 5) وعدد التقييمات، مع عرض النجوم
  في بطاقة المنتج ونافذة التفاصيل ولوحة الإدارة.
- إضافة قائمة ترتيب في صفحة المنتجات: الافتراضي / الأعلى تقييمًا /
  السعر (الأقل أولًا) / السعر (الأعلى أولًا).
- توسيع المنتجات التوضيحية إلى 8 منتجات تشمل تصنيفات إضافية.
- تحديث هوية الألوان إلى لوحة "وردي فاخر" (Rose Gold).
- إدراج رابط Supabase والمفتاح العام ورقم واتساب في config.js.

أولًا: Supabase
---------------
1) افتحي https://supabase.com واختري مشروعك (أو أنشئي مشروعًا جديدًا).
2) من SQL Editor افتحي ملف supabase-schema.sql وانسخي محتواه ثم Run.
   - الملف آمن للتكرار: يضيف حقول التقييم حتى لو كان جدول products موجودًا من V.001.
3) من Authentication > Settings عطّلي Allow new users to sign up.
4) من Authentication > Users أنشئي مستخدم المدير يدويًا ببريد وكلمة مرور.
5) من Storage تأكدي من وجود bucket باسم product-images.

مهم جدًا للأمان:
- استخدمي في المتصفح anon / publishable key فقط. لا تضعي service_role key
  ولا كلمة مرور قاعدة البيانات ولا connection string في أي ملف من ملفات
  المشروع أو في GitHub. هذه البيانات تخص الخادم فقط.
- الحماية تعتمد على سياسات RLS في supabase-schema.sql.
- SQL الحالي يمنح صلاحيات الإدارة لأي حساب Auth مصادق؛ لذلك يجب تعطيل التسجيل العام
  وعدم إنشاء حسابات إلا للمدير/الموظفين الموثوقين.
- هذه النسخة لا تخزن الطلبات في قاعدة البيانات؛ ترسل محتوى السلة إلى واتساب فقط.

ثانيًا: التشغيل والرفع على GitHub
---------------------------------
1) اختبري الملفات محليًا عبر خادم محلي بسيط، أو ارفعيها إلى مستودع GitHub.
2) ارفعي جميع الملفات مع الحفاظ على أسمائها في جذر المستودع.
3) من Settings > Pages اختاري Deploy from a branch.
4) اختاري main ثم /(root) ثم Save.
5) افتحي رابط GitHub Pages. لوحة الإدارة ستكون على /admin.html.

ثالثًا: طريقة الإدارة
---------------------
1) افتحي /admin.html وسجلي الدخول بحساب المدير الذي أنشأتِه في Supabase.
2) أضيفي الاسم والتصنيف والسعر وسعر الخصم والمقاسات والألوان والتقييم وعدد
   التقييمات والوصف والصورة.
3) اختاري نشر المنتج ثم اضغطي حفظ المنتج.
4) سيظهر المنتج في المتجر بعد تحديث الصفحة، ويمكن ترتيبه بالأعلى تقييمًا.

ملاحظات النسخة V.002
--------------------
- المنتجات التوضيحية تظهر فقط عند عدم اكتمال إعداد Supabase.
- السلة تحفظ محليًا في المتصفح.

  للتواصل، واختبرى تجربة الطلب من هاتف مختلف.
